# AI-Искра — образовательный бизнес-симулятор (MVP)

Учебная симуляция на виртуальных деньгах: три раунда (закупка, цена, продвижение) и итоговый экран. Чистые HTML/CSS/JS, ES-модули, без сборки и бэкенда. Банковская интеграция не реализована; логотипы, продукты и условия ВТБ не используются.

## Запуск
ES-модули не работают с `file://`, нужен статический сервер:

    cd ai-iskra
    python3 -m http.server 8080   # затем открыть http://localhost:8080

Деплой: загрузить папку целиком на любой статический хостинг (GitHub Pages, Netlify и т.п.).

## Структура
- `js/data.js` — все параметры: капитал, цены, спрос, продвижение, тексты раундов.
- `js/calculations.js` — чистые финансовые функции и валидация (единственное место формул).
- `js/iskra.js` — шаблонные разборы; получают готовый результат, деньги не пересчитывают.
- `js/game.js` — состояние и переходы между раундами.
- `js/app.js` — отрисовка экранов и обработчики.
- `css/styles.css` — стили. `assets/icons/` — место для официальных материалов команды.

## Правила раундов
Каждый раунд — отдельный сценарий с капиталом 10 000 ₽, деньги и остатки не переносятся. Раунд 1: цена 400 ₽, игрок выбирает закупку. Раунд 2: 24 шт. в наличии, игрок выбирает цену. Раунд 3: цена 450 ₽, игрок выбирает закупку и рекламу. Фиксированные значения раундов меняются в `data.js`.

Порядок разборов Искры: убыток → высокая цена с непроданным товаром → непроданный товар → реклама не окупилась → реклама увеличила продажи → резерв → прибыль → нейтральный.
